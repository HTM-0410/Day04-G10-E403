# fact_check

Use this tool when the user asks to verify the truthfulness of a statement, or asks if something is a fact.

## Inputs

- `claim` (string): The factual claim to be checked.

## Usage constraints

- Do not use this tool for subjective opinions or questions that are not framed as claims.
